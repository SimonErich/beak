# First Flight

Build a panel by describing its data, behavior and presentation. This tutorial follows [the runnable shop](https://github.com/SimonErich/beak/tree/main/examples/clean_beak_config); every example uses that application's models.

Start with the minimal generated app if you have no project yet. Then inspect the shop one resource at a time. The API runs on port 8080 and the panel on port 3000.

1. [Define a resource](01-your-first-resource.md).
2. [Choose fields and shared validation](02-columns-and-validation.md).
3. [Declare relationships](03-relationships.md).
4. [Prepare the database and API](04-seeding-and-the-api.md).
5. [Arrange forms, tables and custom screens](05-shaping-the-panel.md).
6. [Test and ship](06-auth-tests-and-shipping.md).

The maintained examples are `examples/quickstart`, the CLI scaffold, and `examples/clean_beak_config`, the complete application. Both use the same model and resource contracts.
