# The panel

`BeakPanel` accepts resources, custom pages, themes, formatting and an API origin. Resource configuration supplies conventional routes, navigation, typed search and filters. Forms and wizards use one draft runtime, including relationships, model actions and conflict recovery.

Start with [Resources](resources.md), [Forms](forms.md) and [Tables and filters](tables-and-filters.md). For specialized tasks, add [Custom screens](custom-screens.md) or a dashboard. Data blocks and custom widgets can share the panel's source and mutation notifications.
