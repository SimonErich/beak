Worm maps Dart classes to database tables and gives you typed queries over them. Field references are constants, not strings, so a typo is a compile error instead of a runtime surprise. The bird gets the worm; your app gets its data.

```dart
await Worm.initialize(
  config: const WormConfig(),
  adapters: {'default': InMemoryAdapter()},
);

await Worm.adapter().executeSchema(
  const SchemaDescriptor.createTable(table: 'users'),
);

await User(id: 'u1', name: 'Ada', age: 36).save();

final adults = await User.query()
    .where(User$.age.gte(18))
    .orderBy(User$.name)
    .get();
```

One query API, five backends: PostgreSQL, MySQL, SQLite, MongoDB, and an in-memory adapter for tests.
