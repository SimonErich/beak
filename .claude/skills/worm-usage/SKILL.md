# worm-usage

worm is a type-safe, server-side Dart ORM (Postgres/MySQL/SQLite/Mongo/in-memory).
Full reference: `packages/worm` source and its `WORM_AI_SPEC.md`. The rules below are
the ones most often gotten wrong — internalize them.

## Non-negotiable model shape

A queryable, runnable worm model MUST have all of these:

```dart
import 'package:worm/worm.dart';

@Table(name: 'products')            // read by codegen only; NO runtime effect
final class Product extends Model {
  Product({required String name}) {
    setAttribute('id', /* assign yourself — worm never mints PKs */);
    setAttribute('name', name);
  }
  Product._();

  factory Product.fromRow(Map<String, Object?> row) {
    final p = Product._();
    row.forEach(p.hydrateAttribute);
    return p..markPersisted();       // flips exists=true so next save() UPDATEs
  }

  @override
  String get tableName => Product$.tableName;   // REQUIRED or save/query throw
  @override
  Object get id => getAttribute('id') ?? '';
  String get name => switch (getAttribute('name')) { final String v => v, _ => '' };
  @override
  Map<String, Object?> toRow() => {'id': id, 'name': name};

  static QueryBuilder<Product> query() => QueryBuilder<Product>.from(
        QueryContext<Product>(
          adapter: Worm.adapter(),
          table: Product$.tableName,
          hydrate: Product.fromRow,
        ),
      );
}

abstract final class Product$ {
  static const String tableName = 'products';
  static const StringField name = StringField('name');
}
```

Rules that bite:
- `Product.query()` does **not** exist unless you declare the `static query()` above,
  OR you call the codegen-emitted `ProductQuery.query()` extension static. It is NOT
  inherited from `Model`.
- `@Table(name:)` is compile-time only. Runtime table resolution is the `tableName`
  override (or a `ModelRegistration` at `Worm.initialize`). Missing → throws
  `ConfigurationException('model.tableName.missing')`.
- Codegen wiring is `part 'product.g.dart';` (the `.g.dart` suffix, never `.worm.dart`),
  generated by `dart run build_runner build --delete-conflicting-outputs` (wrapped by
  `dart run worm:worm gen`). There are **no macros**.
- Field companions gate operators by type: `StringField` (text), `ComparableField<T>`
  (int/double/num/DateTime — unlocks `gt/gte/lt/lte/between`), `Field<T>` (everything
  else). `User$.age.gte('18')` does not compile. That is the feature.

## Queries (immutable builder — always use the return value)

```dart
final adults = await User.query()
    .where(User$.age.gte(18))                 // typed predicate
    .where(User$.name, 'Alice')               // (field, value) equality sugar
    .where(User$.age, Operator.gte, 65)       // (field, op, value)
    .orderBy(User$.age, descending: true)
    .limit(25).offset(50)
    .get();                                    // terminal: List<User>
// also: .first() -> User?, .firstOrFail(), .count(), .exists(), .pluck(field), .paginate(...)
```
`where()` returns a NEW builder; `q.where(...)` without reassigning is a no-op bug.

## Relations — declare, then EAGER-load (no lazy loading)

```dart
@HasMany(Post, onDelete: OnDelete.ormCascade) final List<Post> posts;
@BelongsTo(User) final User? user;
@BelongsToMany(Role) final List<Role> roles;
```
```dart
final users = await User.query().withRelations([User$.posts, User$.profile]).get();
final withComments = await User.query().withNested(User$.posts.include([Post$.comments])).get();
final filtered = await User.query().withRelation(User$.posts, Post$.published.eq(true)).get();
```
Reading an un-loaded relation throws. Batching: HasOne/HasMany/BelongsTo/Morph* = 1
query; BelongsToMany/*Through/MorphToMany = 2. Use this batching for Beak's reference
deduplication (`query.with([...])`).

## Migrations (explicit, registered, never auto-applied)

```dart
final class CreateProductsTable extends Migration {
  const CreateProductsTable();
  @override String get name => '20260101_120000_create_products_table';
  @override Future<void> upSchema(Schema schema) async {
    await schema.create('products', (t) {
      t.idUuid();
      t.string('name');
      t.decimal('price', precision: 10, scale: 2);
      t.string('status')..withDefault('draft');
      t.uuid('category_id')..makeNullable();
      t.timestamps();
      t.softDeletes();
      t.index(['status']);
      t.foreign(column: 'category_id', references: 'id', on: 'categories', onDelete: OnDelete.setNull);
    });
  }
  @override Future<void> downSchema(Schema schema) async => schema.drop('products', ifExists: true);
}
```
Column modifiers mutate in place and return void → use cascades (`..makeNullable()..makeUnique()`).
Register every migration in the project's `bin/worm.dart` `CliContext.migrations`.

## Seeders & factories

```dart
final class ProductSeeder extends Seeder {
  @override String get name => 'ProductSeeder';
  @override Future<void> run(DatabaseAdapter adapter) async { /* insert known rows */ }
}
final class ProductFactory extends Factory<Product> {
  @override Product definition() => Product(name: faker.food.dish());
}
```

## Test harness (use this exact pattern)

```dart
setUp(() async { Worm.seedRandom(42); await createTestDatabase(); });
tearDown(Worm.reset);   // NOT optional — a second Worm.initialize without reset throws
```
- `createTestDatabase()` connects an `InMemoryAdapter`, `executeSchema(...)` the tables,
  and calls `Worm.initialize(...)`.
- Golden query tests need no DB: `expect(User.query().where(User$.age.gte(18)).toSql(), '...')`.
- To assert query counts (N+1 regressions), wrap in `LoggingAdapter` + `InMemoryQueryLogger`.
- `InMemoryAdapter` throws on raw SQL — use `SqliteAdapter.memory()` for raw-SQL paths.

## Never do
No macros. No `Worm.postgres()`/`Worm.sqlite()` constructors (build the adapter, then
`Worm.initialize`). No Mongo multi-doc transactions. No lazy loading. No identity map.
